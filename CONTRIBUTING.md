# Contributing

Thanks for helping. This is a one-person indie project, so keep it simple.

- **Fixes** (typos, broken links, wrong facts): open a pull request or an issue. Please include a source for factual corrections.
- **Skill improvements**: pull requests to `skills/` are welcome. Keep each skill standalone, free to use, and free of secrets, personal data, and paid-service requirements. By contributing to `skills/` you agree your change is licensed under MIT.
- **Posts and page text**: changes to `content/` are licensed under CC BY 4.0.
- **Requests and ideas**: use the [Request form](https://github.com/klanarongz2009-sketch/BlogPost/issues/new?template=request.yml).
- **Do not** include personal information, tokens, or passwords in issues or pull requests.

Reviews can take a long time, and some may never happen. See the [project notice](PROJECT_NOTICE.md).
