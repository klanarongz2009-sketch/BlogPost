# MiniApps

Each MiniApp here is a new app that one AI built from scratch from my spec. I write the idea and judge the result; the AI does the build. Each entry names the AI that made it. Links were checked on 2026-11-21.

- **[Lumen OS: A Phone OS Built by AI](https://osim.space-z.ai/)**: built by **Z.ai**. A phone OS concept that opens in the browser.

More MiniApps will be added as other AIs build them.

## Note for indie makers (opinion)

Give the same small idea to more than one AI and compare what each one builds. It is a free way to learn which AI fits which kind of app, and you keep the best result.
