# เกี่ยวกับผม

ผมใช้ชื่อ **Bogus** และทำเพลงในชื่อ **Klasster** ผมเป็นคนทำงานอินดี้ ไม่มีบริษัท ไม่มีทีม และไม่มีงบ

## งานที่ผมทำ

ผมเรียกตัวเองว่า **AI operator** และ **digital architect** ในทางปฏิบัติคือ:

- ผมเขียน spec ว่างานต้องทำอะไร ต้องทำตามกฎอะไร และแบบไหนถึงนับว่าเสร็จ
- ผมสั่งงาน AI agent ที่ลงมือทำส่วนใหญ่ เช่น code เอกสาร release และการตรวจ
- ผมตรวจและทดสอบผล แล้วส่งงานกลับถ้ายังผิด

ผมไม่ได้อ้างว่าเทรน foundation model เอง โปรเจกต์ของผมใช้โมเดลที่มีอยู่แล้ว ส่วนใหญ่เป็นโมเดลฟรี local หรือ open-weight แล้วครอบด้วยกฎ tool และ test

## ทำไมต้อง "อินดี้เพื่ออินดี้"

คู่มือ AI ส่วนใหญ่คิดว่าเรามีแพ็กเกจเสียเงิน มีทีม หรือมีเครื่องแรงๆ ผมไม่มีสักอย่าง สิ่งที่ใช้ได้จริงสำหรับผมคือ free tier ที่รีเซ็ตได้ โมเดล local และ open-weight และ agent ที่ทำงานต่อได้ตอนผมไม่อยู่ ผมจดไว้ที่นี่เพื่อให้คนทำงานอินดี้คนอื่นเอาส่วนที่ใช้ได้ไปใช้ต่อ

## วิธีทำงานที่ผมชอบ

นี่คือกฎส่วนตัวของผม ไม่ใช่คำแนะนำสำหรับทุกคน:

- **หลักฐานสำคัญกว่าคำอ้าง** AI บอกว่า "เสร็จแล้ว" หรือ "ไม่เจอ" ยังไม่ใช่หลักฐาน ต้องตรวจไฟล์ ผล test หรือหน้าเว็บจริง
- **แยกข้อเท็จจริง สมมติฐาน และสิ่งที่ยังไม่รู้** ทุกรายงานต้องบอกว่าข้อไหนเป็นแบบไหน
- **ของฟรีก่อน** ผมเลี่ยงบริการเสียเงิน ถ้าอะไรมีค่าใช้จ่ายจริงต้องบอกตรงๆ
- **ให้ agent ทำจนจบ** ผมอยากให้ agent ทำงานให้เสร็จ มากกว่าส่งขั้นตอนกลับมาให้ผมทำเอง
- **ความเป็นส่วนตัว** งานสาธารณะไม่มีข้อมูลส่วนตัว
