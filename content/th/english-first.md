# ทำไม README ของผมขึ้นต้นด้วยภาษาอังกฤษ แล้วแยกภาษาไทยเป็นอีกไฟล์

ฉบับภาษาอังกฤษ: [English](../../posts/2026-11-21-english-first-readme/) · 21 พ.ย. 2026

สิ่งที่ผมเห็นบ่อยในรีโพของนักพัฒนาไทย คือ README เปิดด้วยภาษาไทย แล้วภาษาอังกฤษอยู่ล่างสุด หรือไม่มีเลย อันนี้เป็นสิ่งที่ผมสังเกตเอง ไม่ใช่ผลสำรวจ ด้านล่างเป็นตัวอย่างจริงหนึ่งตัวอย่าง ตามด้วยเหตุผลที่ผมทำกลับกัน

## ตัวอย่าง: Kreycin

[Kreycin](https://github.com/Kreycin) เป็นคนทำงานชาวไทยที่ปล่อยชุดเครื่องมือทำแอนิเมชันและเครื่องมือ AI งานดี และเขียนให้คนไทยอ่านอย่างชัดเจน ผมเลือกมาเป็นตัวอย่างเพราะแบบนั้น ไม่ได้ตั้งใจวิจารณ์ ผมอ่าน README ทุกรีโพในบัญชีนี้เมื่อ 21 พ.ย. 2026:

- **ไทยก่อน อังกฤษอยู่ล่าง:** [pdoom-mv-kit](https://github.com/Kreycin/pdoom-mv-kit) (หัวข้อ `## English` เริ่มราวบรรทัด 91 จาก 110), [pdoom-3d-kit](https://github.com/Kreycin/pdoom-3d-kit) (บรรทัด 83 จาก 99) และ [Auto-Prompt-Image-Extension-Gemini-](https://github.com/Kreycin/Auto-Prompt-Image-Extension-Gemini-) (ภาษาอังกฤษเริ่มบรรทัด 51)
- **ไทยเป็นหลัก ไม่มีส่วนภาษาอังกฤษ:** [Auto-Caption](https://github.com/Kreycin/Auto-Caption) หัวข้อและขั้นตอนเป็นภาษาไทย
- **ไทยกับอังกฤษอยู่บรรทัดเดียวกัน:** [thai-docs-to-excel](https://github.com/Kreycin/thai-docs-to-excel) เช่นหัวข้อ "ติดตั้งและใช้งาน / Install and run"
- **อังกฤษก่อน ไทยอยู่ล่าง:** [scope](https://github.com/Kreycin/scope) ซึ่งเป็น Claude Code plugin
- **อังกฤษ:** [ton-sea](https://github.com/Kreycin/ton-sea) มีภาษาไทยแค่ในชื่อเรื่อง

ผมไม่นับรีโพ frontend 2 ตัวที่ยังเป็น README ตั้งต้นของ framework และอีก 1 ตัวที่ไม่มี README.md

แม้แต่ในบัญชีเดียวก็ยังปนกัน 3 ใน 7 รีโพเปิดด้วยไทยแล้วไว้อังกฤษข้างล่าง และอีก 1 รีโพเป็นไทยเป็นหลัก ส่วน 2 รีโพที่ขึ้นต้นด้วยอังกฤษเป็นเครื่องมือที่ใช้ได้กว้างที่สุด คือ Claude Code plugin กับหนังแอนิเมชันที่ทำด้วยโค้ดล้วน

## ทำไมผมขึ้นต้นด้วยภาษาอังกฤษ

- **หน้าจอแรกตัดสินทุกอย่าง** คนที่เข้ามาในรีโพจะอ่านส่วนบนสุด ถ้าไม่ใช่ภาษาที่อ่านได้ก็ปิดไป คนที่จะใช้ กดดาว หรือช่วยแก้เครื่องมือสำหรับนักพัฒนาบน GitHub ส่วนใหญ่อ่านภาษาอังกฤษ ถ้าส่วนบนเป็นภาษาไทย คนส่วนใหญ่จะไม่เลื่อนลงไปหาส่วนภาษาอังกฤษ
- **ระบบค้นหาและ AI agent ก็อ่านจากบนลงล่าง** GitHub search, link preview และ AI coding agent ที่ถูกสั่งให้อ่านรีโพ เริ่มจากส่วนบนของ README.md ทั้งหมด สรุปภาษาอังกฤษตรงนั้นทำให้หารีโพเจอง่ายขึ้น และ agent ใช้งานได้ถูกต้องขึ้น
- **งานสาธารณะของผมตั้งใจให้ทุกคนใช้** งานที่เผยแพร่ผมใช้ภาษาอังกฤษ ส่วนงานส่วนตัวหรืองานในพื้นที่ใช้ภาษาไทย เครื่องมือ dev, skill หรือโมเดลอย่าง Tagentic1 ไม่มีเหตุผลที่จะจำกัดไว้แค่คนอ่านภาษาเดียว

## ทำไมภาษาไทยแยกเป็นอีกไฟล์

- **แต่ละภาษาครบในตัวเอง** ส่วนภาษาไทยที่อยู่ท้าย README ภาษาอังกฤษมักตามไม่ทัน แก้อังกฤษแล้วลืมแก้ไทย พอแยกเป็น `README.md` กับ `README.th.md` ที่ครบทั้งสองไฟล์ ผมเทียบได้ว่าเนื้อหาตรงกัน ใน [ter-ai](https://github.com/klanarongz2009-sketch/ter-ai) ประกาศโปรเจกต์ก็แยกแบบนี้ เป็น `PROJECT_NOTICE.md` กับ `PROJECT_NOTICE.th.md`
- **ไม่มีใครต้องเลื่อนผ่านภาษาที่อ่านไม่ออก** คนอ่านอังกฤษได้อังกฤษตั้งแต่บรรทัดแรก คนอ่านไทยกดลิงก์เดียวด้านบนแล้วได้ภาษาไทยตั้งแต่บรรทัดแรก
- **ภาษาไทยได้พื้นที่เต็ม ไม่ใช่คำแปลที่ถูกเบียดไว้มุมหนึ่ง** ไฟล์แยกทำให้ข้อความภาษาไทยมีพื้นที่และโครงสร้างเท่ากับภาษาอังกฤษ

## เมื่อไรควรขึ้นต้นด้วยภาษาไทย (ความเห็น)

ถ้ากลุ่มเป้าหมายเป็นคนไทย ขึ้นต้นด้วยไทยคือทางที่ถูก ชุดเครื่องมือของ Kreycin มาพร้อมคลิป YouTube ภาษาไทย และเขียนให้คนที่ดูคลิปนั้น การขึ้นต้นด้วยไทยจึงเหมาะ กฎของผมง่ายๆ คือเขียนหน้าจอแรกให้คนที่อยากให้เห็นมากที่สุด สำหรับงาน dev สาธารณะของผม คนกลุ่มนั้นคือทุกคน จึงขึ้นต้นด้วยอังกฤษ และมีลิงก์เดียวที่ชัดเจนไปยังฉบับภาษาไทยเต็ม
