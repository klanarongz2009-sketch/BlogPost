Projects

TER-AI

TER-AI is my offline-first Thai AI toolkit (MIT). From its README: typo-tolerant intent routing, local chat and vision, speech synthesis, SVG graphics, and music creation. The intent router is 1.1 MB, runs on CPU, has no runtime dependencies, and works offline: give it one Thai or Thai-English message and it returns one of 15 intents. Try the web demo.

TER-AI is an indie project and may pause or close with little warning. Its project notice says why.

Tagentic1

Tagentic1 is a local thinking-and-agentic model setup inside the TER-AI project: short visible reasoning steps, tool use, and four memory files (User.md, Systemprompt.md, Memory.md, Systemskill.md). It is a work in progress. My own test found it drops a space between Thai words in exact-copy tasks (issue #18).

Telegram bot @Terai_F0_bot

@Terai_F0_bot is the Telegram bot for Tagentic1. Bot system messages are in English; the AI replies in the language it writes in. Anyone can suggest knowledge with /add. Suggestions go to a queue and are checked against sources before they are added to the shared knowledge file. Public users cannot read private files or run commands. The bot can stop at any time.
