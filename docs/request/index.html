What happens next:

  • A bot named BlogPostIdeas may reply first. It is an AI, not Bogus. It runs on Wabi, an AI assistant platform.
  • The request is passed to Bogus's own AI assistant, which logs it and tells him.
  • Bogus may take a long time to see it, and may not act on it. There is no promised response time. See the project notice.

Please do not put personal information, passwords, or anything private in a request. Requests are public.
