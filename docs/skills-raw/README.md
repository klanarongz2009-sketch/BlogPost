# Free skill library

Eight standalone `SKILL.md` files for AI agents, written for indie makers. MIT licensed, free, provided as is.

Install: copy a skill folder into the skills folder your agent reads, or paste the `SKILL.md` contents into your assistant's custom skill or custom instructions. Each file starts with YAML front matter (`name`, `description`) followed by plain-language instructions.

See the [skill library page](https://klanarongz2009-sketch.github.io/BlogPost/skills/) for what each one does.
