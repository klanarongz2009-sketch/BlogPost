ขอให้ทำอะไรสักอย่าง

อยากได้บทความเรื่องใด skill ฟรีตัวใหม่ ไอเดีย MiniApp หรือให้แก้อะไร เปิดคำขอได้ที่นี่:

เปิดคำขอบน GitHub

หลังจากนั้น:

  • บอทชื่อ BlogPostIdeas อาจตอบก่อน บอทนี้เป็น AI ไม่ใช่ Bogus และทำงานบน Wabi ซึ่งเป็นแพลตฟอร์ม AI assistant
  • คำขอจะถูกส่งต่อให้ AI assistant ของ Bogus ซึ่งบันทึกคำขอและแจ้ง Bogus
  • Bogus อาจเห็นคำขอช้ามาก และอาจไม่ทำตามคำขอ ไม่มีการรับประกันเวลาตอบ อ่าน ประกาศโปรเจกต์

อย่าใส่ข้อมูลส่วนตัว รหัสผ่าน หรือเรื่องส่วนตัวในคำขอ เพราะคำขอเป็นสาธารณะ
